# Landing component structure

- `Landing.tsx` - page composition
- `landing/LandingNav.tsx` - public navigation and dashboard entry
- `landing/LandingHero.tsx` - hero copy, poster, and video
- `landing/LandingProof.tsx` - performance metrics
- `landing/LandingCollection.tsx` - featured vehicle collection
- `landing/LandingViewing.tsx` - private-viewing call to action
- `landing/landingMedia.ts` - centralized media paths and vehicle data

## Add media

Use `public/media/README.md` for the exact filenames and folder layout.
