# HongT public media

Place optimized website assets in these folders:

- `public/media/landing/hero/` - hero poster and hero video
- `public/media/landing/vehicles/` - landing collection vehicle images
- `public/media/vehicles/exterior/` - vehicle exterior gallery
- `public/media/vehicles/interior/` - vehicle interior gallery
- `public/media/vehicles/details/` - engine, wheel, trim, and detail shots

## Landing page filenames

- `hero-poster.webp` - desktop/mobile hero fallback poster
- `hero-loop.mp4` - short muted hero video
- `hero-loop.webm` - WebM fallback
- `v1-carbon.webp`
- `gt-track.webp`
- `xs-spider.webp`

Recommended formats:

- Images: WebP or AVIF
- Hero video: MP4 H.264 plus WebM VP9
- Keep MP4/WebM under 20 MB where possible
- Use descriptive alt text in component data
